# OpenAPI 3.1 spec + Redoc viewer under hidden admin page

> Source: GitHub issue [#368](https://github.com/seanmousseau/Simple-WP-Helpdesk/issues/368) — snapshot captured 2026-05-27.

Ship a machine-readable API contract that doubles as integrator docs.

## Deliverables

- `docs/openapi.yaml` (OpenAPI 3.1) describing every `swh/v1` endpoint, request/response schemas, auth schemes, error codes
- Admin page at Tools → API Reference (or hidden under Settings → Integrations) that renders the spec with Redoc (vendored, not CDN — avoids third-party runtime dep)
- Public accessor at `swh/v1/openapi.json` (no auth) returning the spec as JSON — lets tools like Postman / Insomnia one-click import

## Consistency

- Every schema component named `Ticket`, `Reply`, `Category`, etc., referenced with `\$ref` — no inlined duplicates
- Error envelope documented once: `{ code, message, data?: { status: int } }`
- Examples inline on each endpoint

## Acceptance criteria

- Spec validates against OpenAPI 3.1 schema (CI step via `swagger-cli validate` or equivalent)
- Spec version bumps with every breaking change to the API
- Redoc loads offline (Playwright: `window.navigator.onLine = false` then open page)
