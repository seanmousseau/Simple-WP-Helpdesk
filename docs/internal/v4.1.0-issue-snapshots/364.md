# REST API v1: read-only endpoints for technicians, categories, settings

> Source: GitHub issue [#364](https://github.com/seanmousseau/Simple-WP-Helpdesk/issues/364) — snapshot captured 2026-05-27.

Ancillary endpoints so integrations can populate dropdowns and respect site configuration.

## Endpoints

- `GET /users/technicians` — users with `edit_posts`, returning `{id, display_name, email}`. Needs `edit_posts` / API read.
- `GET /categories` — `helpdesk_category` taxonomy terms with `{id, name, slug, parent, count}`.
- `GET /settings/public` — subset of settings safe to expose (priority labels, status labels, SLA thresholds, enabled features). **Never** return secrets (inbound webhook secret, SMTP creds, email template bodies).

## Acceptance criteria

- Explicit allowlist for `settings/public` — new settings are opt-in
- No PII on `users/technicians` beyond display name + email; hide email if `swh_hide_staff_email` filter returns true
- Playwright checks allowlist enforcement (add a secret to options, confirm it's absent from response)
