# Opt-in API access audit log (last 10 accesses per ticket)

> Source: GitHub issue [#369](https://github.com/seanmousseau/Simple-WP-Helpdesk/issues/369) — snapshot captured 2026-05-27.

For compliance-minded admins, record who (which key) accessed a ticket via API.

## Toggle

Settings → Integrations → "Enable API access log" checkbox. Off by default.

## Storage

- Post meta `_swh_api_access_log` on each ticket
- Array, max 10 entries, FIFO
- Each entry: `{ ts, key_id, key_label, action (read/write), route }`

## Display

- Meta box "API Access" in ticket editor (collapsible, shown only when log feature enabled)
- Columns: timestamp, key label, action, route

## Privacy

- No request body logged — just route + action
- Respects data retention cron: log entries older than `swh_retention_*` purged with the ticket

## Acceptance criteria

- Log writes don't affect API response time (measured: < 5ms overhead)
- Disabling feature does not delete existing log entries (idempotent)
